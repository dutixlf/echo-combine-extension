# Echo Combine Extension

An extension for [Echo](https://github.com/brahmkshatriya/echo) that allows you to combine **Metadata Provider** (e.g., Spotify, Tidal) with **Audio Stream Provider** (e.g., YouTube Music). 

It intelligently proxies UI, feeds, and interactions to the metadata extension while intercepting playback requests to resolve actual audio streams from the stream extension.

## Configuration
Inside the Echo app:
1. Go to **Settings -> Extensions**.
2. Tap on the **Combine Extension** settings icon.
3. Select your preferred **Metadata Extension** from the dropdown list.
4. Select your preferred **Stream Extension** from the dropdown list.
